#### E-Codes

Exception codes are PrimSys method of determining controlled exceptions, these are different from errors or crashes since they are intended functionality marking controlled errors wich are handled correctly, further functionality of error detection and crash handling may be added as modules.

##### List of all E-Codes

Following is a comprehensive list of all existing E-Codes for the installed release:

1. E1 = Yet to be implemented, it will only appear in development builds.
2. E2 = No Operation implemented.
3. E3 = Invalid Command Inserted.
4. E4 = Too many Arguments.
5. E5 = No Arguments Provided.
