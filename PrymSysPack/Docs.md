### PrimSysPack

the primsyspack package is the main **Section** manager for PrimSys, it allows fucntionality to access PrimSys Sections Independently and load there packages permitting their fucntionality without modification of the source code, it expands the fucntionality of the PrimSysCore Package manager, by automatically finding and downlading dependencies.
